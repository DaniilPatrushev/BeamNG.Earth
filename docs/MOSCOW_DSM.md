# Москва / места без лидара: сводка работы (ветка `moscow-dsm`, 2026-10-21)

Документ для продолжения работы с другого устройства (в т.ч. новой сессией Claude: «прочитай docs/MOSCOW_DSM.md»).

## Цель
Форк `DaniilPatrushev/BeamNG.Earth`. Москва и область: «нормально везде проехать», идеальная достоверность не нужна.
Жалобы: дороги кривые вверх-вниз (и чуть влево-вправо), мост лежит на перпендикулярной дороге, резкий уклон при
переходе дороги в мост, объекты на дороге (куб-кусок здания, каменный барьер), летающие светофоры.

## Диагноз
- Под Москвой у Mapterhorn нет тайлов глубже z12 (z13/z14 над 55.75,37.62 -> 404) => рельеф = Copernicus GLO-30
  (30 м, модель ПОВЕРХНОСТИ: кроны, крыши), почищенный фильтром `server/dsmground.py` (морфологическое открытие
  окном 400 м). Все константы дорог/мостов настраивались на лидаре США/Европы.
- Кочки: профиль дороги сглаживался σ=12 м, а остатки DSM имеют длину волны 30-150 м.
- Мост на дороге: фильтр 400 м стирает насыпи развязок; подъём подходов (`grading._lift_approaches`) был выключен для
  motorway/trunk и съездов (почти все развязки Москвы); в плотной застройке подъём ещё и обрезался соседними дорогами.
- «Каменный барьер» = подпорные стенки `roads.retaining_walls` (срабатывали на кочках DSM, вставали на чужие дороги).
- «Куб» = ML-контуры зданий Microsoft/Google (фуры, киоски) — отсекались только в 4 м от осевой.
- Летающие светофоры: высота брались с центра перекрёстка, а стоят они в 2.5-25 м от него, на откосе.

## Что сделано (коммит 4127f0b + этот файл)
Один переключатель **DSM-режим** (`server/dsmmode.py`): `is_dsm(lat, lon)` по z12-тайлу (нет лидара => DSM).
`BNE_DSM_MODE=auto|on|off`. В лидарных местах поведение байт-в-байт прежнее. Регистрация Dem — только в боевом
запуске (`earthd.main_async`, воркеры через env `BNE_DSM_REGISTER`), не в тестах.

| Что | Где | Суть |
|---|---|---|
| Профиль дорог | `grading.dsm_profile` | нижний 20-й перцентиль по 90 м -> Гаусс 45 м (грунтовки 20 м) -> ограничение уклона 8 % / 14 %; концы точечно отражены (`_smooth_pinned`) |
| Стыки | `grading.snap_profile`, `Grader._snapped_z` | каждый контакт дорог (конец на дороге, пересечение) на одной высоте: старший класс побеждает, равные — среднее; затухание 120 м; старшие соседи берутся уже «сшитыми» |
| Эстакады | `grading._lift_approaches`, `approach_add(side_run)` | подъём подходов для всех классов и съездов, до 8.5 м; откос к соседям 0.5 (как стенка); вторая проезжая часть, идущая на свой мост, не ограничивает |
| Стенки | `roads.retaining_walls`, `grade_points(wall_cut)` | в DSM нет; нигде — на чужой проезжей части |
| Здания | `buildings.carriage_lines`, `_on_carriageway` | в DSM: ML-контур на проезжей части — убрать; здание/часть, через которое улица идёт 3-15 м — убрать |
| Светофоры/знаки/столбы | `furniture._on_ground`, `place(ground=)`, `navgraph._signals(ground=)` | высота земли в своей точке (везде); головы светофоров на мостах не ставятся |
| Локальный DEM | `server/localdem.py`, `dem.Dem.local`, `tools/fabdem_import.py` | см. раздел FABDEM |
| Аудит | `tools/road_audit.py --at lat,lon --compare` | неровность (d2 на 10 м), уклоны по классам, ступеньки стыков, просвет под мостами — DSM off vs on |
| Тесты | `tools/test.sh` | модули параллельно, без тяжёлых сквозных: ~5 мин вместо ~45; `tools/test.sh grading dsm` — секунды; `--all` |

Тесты: новые в `server/tests/test_dsm.py` (17). Падения, которые были ДО работы и не связаны с ней:
`test_launcher_linux` (2), `test_roads.test_bare_verge_beside_roads`, `test_e2e`, `test_integration_drive`.
Под параллельной нагрузкой флапают тайминговые: `test_colormatch.per_tile_cost`, `test_credits` session, `test_server` session.

   ставить -> через ~20 мин Artifacts -> `windows` -> `BeamNG.Earth-1.5.4-beta.exe`. Или локально:
   `python tools/build_native.py; pip install pyinstaller -r server/requirements.txt; python tools/build_bootloader.py;
   python tools/build_app.py` (нужны Python 3.12, Rust, VS Build Tools C++). Или без сборки: `run_server.bat` + игра.
2. Почистить кэш (кроме `mapdata`) или через настройки мода, иначе возьмутся старые тайлы.
3. Сравнение со старым: `set BNE_DSM_MODE=off` перед запуском сервера.
4. Места: МКАД, ТТК, Ленинградка, лесные дороги области. Присылать координаты проблем -> `tools/road_audit.py`.

## FABDEM — всё в одном месте

**Что это.** Forest And Buildings removed Copernicus DEM, V1-2 (Hawker et al. 2022, Environ. Res. Lett. 17 024016;
University of Bristol / Fathom). Тот же Copernicus GLO-30 (30 м), но нейросеть, обученная на лидарных областях,
вычла из него деревья и здания => модель ЗЕМЛИ. По статье ошибка в лесах падает примерно вдвое (~5 м -> ~2-3 м),
в застройке тоже заметно (порядки величин, не перепроверял).

**Зачем, если уже есть фильтр `dsmground`.** У фильтра три слабых места, все бьют по Подмосковью:
1. леса шире 400 м остаются (земля на высоте крон 15-25 м, ступеньки на опушках; просека дороги уже пикселя => дорога
   прыгает) — DSM-режим это только сглаживает, причину убирает FABDEM;
2. срезает насыпи/дамбы/путепроводы (узкие) => мосты ложились на дороги (сейчас костыль: подъём подходов по OSM);
3. в городе остаются горбы 1-2 м по краям кварталов.

**Что даст.** Леса области — главный выигрыш; насыпи и выемки сохраняются (подъёмы подходов станут реже/мягче);
город — ровнее под домами; склоны и долины рек точнее.

**Чего не даст.** Разрешение то же 30 м (кюветы, мелкие насыпи не видны, сглаживание дорог остаётся нужным); мосты не
знает (остаётся логика OSM); местами артефакты в плотной застройке и у воды.

**Лицензия.** CC BY-NC-SA 4.0 — только некоммерческая. Для личной игры ок; распространять данные с модом/продавать
нельзя. Поэтому сервер сам НЕ качает — файлы скачивает пользователь.

**Как подключить.**
1. Скачать с https://data.bris.ac.uk/data/dataset/s5hqmjcdj8yo2ibzi9b4ew3sn (DOI 10.5523/bris.s5hqmjcdj8yo2ibzi9b4ew3sn):
   `N50E030-N60E040_FABDEM_V1-2.zip` (Москва и почти вся область, несколько ГБ) и `N50E040-N60E050_FABDEM_V1-2.zip`
   (восточный край области). Внутри — 1°x1° COG GeoTIFF вида `N55E037_FABDEM_V1-2.tif`.
2. `python tools/fabdem_import.py путь\к\архиву.zip --bbox 54.2,35.1,56.98,40.25`
   -> `~/.cache/beamng-earth/dem/local/fabdem/N55E037.npy` (float32, строка 0 = север, NaN = нет данных),
   ~20-30 файлов по 35-50 МБ. Читает zip, вложенные zip, папки, tif.
3. Перезапустить сервер. В логе: `local elevation: N cells of fabdem`; в титрах на экране «FABDEM».
4. Откат: `set BNE_LOCAL_DEM=off` или удалить папку `dem/local`.

**Как устроено в коде.**
- `localdem.LocalDem` сканирует `<cache>/dem/local/<source>/*.npy`, билинейная выборка по пиксельной сетке
  (pixel-is-area, размер массива задаёт шаг: у Copernicus/FABDEM на 50-60° ширина 2400 px).
- `dem.Dem._load_tile`: для тайлов z >= 10, где есть локальные клетки, — только локальные высоты (без
  `dsmground`, это уже модель земли); на краю покрытия плавный переход в Mapterhorn на 48 px. Локальные тайлы НЕ
  кладутся в декодированный кэш-зеркало (пересчитываются, ~10 мс), поэтому старые зеркальные тайлы не мешают.
- Вертикальный датум FABDEM = EGM2008, как у Copernicus в Mapterhorn => сдвиг на стыке не нужен.
- `dem.served[key] = "local:fabdem"` -> титры: `credits.ELEVATION["local:fabdem"]` (полная) и `"FABDEM"` (кратко),
  запись в CREDITS.md.
- DSM-режим над FABDEM остаётся включённым (те же 30 м) — сглаживание дорог работает и дальше.

**Риски / не проверено.**
- На настоящих файлах FABDEM не проверялось — только синтетический TIFF. FABDEM — COG с deflate и float-предиктором;
  если Pillow не прочтёт, импорт сам попробует `tifffile` (`pip install tifffile imagecodecs`).
- Совет: сначала поездить без FABDEM, потом подключить и сравнить те же места (особенно лесные дороги).
